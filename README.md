# Portfólio — Ruy Pinheiro Rodrigues Filho

Currículo online desenvolvido para a atividade prática da disciplina de desenvolvimento web (UNINTER), usando apenas **HTML5, CSS3 e JavaScript puros**, sem frameworks.

**Site publicado:** https://ruyfilho77.github.io/portfolio-ruy-filho/

## Páginas
- `index.html`: Sobre mim
- `formacao.html`: Formação
- `portfolio.html`: Portfólio
- `contato.html`: Contato (formulário com validação e simulação de envio)

## Funcionalidades em JavaScript
- Validação do formulário (campos obrigatórios e formato do e-mail) e modal de confirmação
- Menu responsivo (hambúrguer) em telas pequenas
- Tema claro/escuro com a escolha salva no navegador
- Simulador de juros compostos (`projetos/simulador-juros/`)

## Estrutura
```

├── index.html

├── portfolio.html

├── css/estilo.css
```
